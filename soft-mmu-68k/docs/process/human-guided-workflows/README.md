# Human-Guided Workflows

This area selectively preserves human-guided execution and learning workflows that have durable value for understanding how SM68861 project work was performed.

These records are historical process/learning collateral. They are not live packet-control records and do not override merged code, tests, approved packet Issues or packet definitions, reviewed pull-request/CI evidence, or current project documentation.

Historical interaction language may remain intentionally, including step-to-step handoffs, requests to return output to a coach, branch names, and intermediate verification state. Preserving a workflow here does not establish a rule that every chat-generated instruction or status note should be committed.
